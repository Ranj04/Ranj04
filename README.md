## Selected Work

**RescueOps** — Autonomous Incident Responder<br>
<sub>A five-agent CrewAI pipeline (triage → diagnosis → remediation → verification → postmortem) with human-approval gates before any destructive action. Routes through a TrueFoundry AI Gateway with multi-model fallback, plus a live chaos console and ground-truth evaluation dashboard.</sub><br>
<sub>`CrewAI` · `FastAPI` · `React` · `TrueFoundry`</sub>

**Expense-Approval Agent**<br>
<sub>Autonomous receipt processing: Gmail → LLM extraction → Google Sheets → Telegram, with a custom polling layer for near-real-time triggering. Built on the Composio v3 SDK behind a FastAPI webhook.</sub><br>
<sub>`Composio` · `FastAPI` · `Gemini`</sub>

**Second Opinion / Parts Oracle** — Repair-Quote Analyzer<br>
<sub>Flags overcharges by analyzing car repair quotes against a reference price table. The Parts Oracle variant runs autonomously — monitoring retailer prices, computing benchmarks in ClickHouse, and publishing cited reports.</sub><br>
<sub>`FastAPI` · `React` · `ClickHouse` · `Gemini`</sub>

**Sports Betting Analytics**<br>
<sub>NBA player-prop modeling with closing-line-value validation against Pinnacle. Separate minutes-projection and per-stat production models, historical ingestion via `nba_api`, ESPN endpoints as live fallback.</sub><br>
<sub>`Python` · `nba_api` · `Modeling`</sub>
