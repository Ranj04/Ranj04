## 👋 About

I build autonomous, multi-agent systems that do real work — not demos. My focus is agent orchestration, RAG pipelines, and full-stack apps that put LLMs behind deterministic guardrails so the math is never hallucinated.

- 🔭 Currently building autonomous incident-response and analytics agents on **CrewAI**, **FastAPI**, and **React**
- 🧠 Into multi-agent architectures, RAG, model fine-tuning (LoRA/Unsloth), and LLM gateways/routing
- 🏎️ Side interests: OBD-II diagnostics & car tech, NBA/UFC, personal medicine, and sports analytics
- 📫 Reach me: ranjiv.jithendran@gmail.com · [LinkedIn](https://www.linkedin.com/in/ranjiv-jithendran/) · [ranjiv.dev](https://ranjiv.dev)

## 🚀 Featured Projects

### 🛟 RescueOps — Autonomous Incident Responder
A five-agent CrewAI pipeline (triage → diagnosis → remediation → verification → postmortem) for autonomous incident response, with human-approval gates before any destructive action. Routes through a TrueFoundry AI Gateway with multi-model fallback, FastAPI backend, React frontend, and a live chaos console plus ground-truth evaluation dashboard.

![CrewAI](https://img.shields.io/badge/CrewAI-FF5A36?style=flat-square&logoColor=white) ![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white) ![React](https://img.shields.io/badge/React-61DAFB?style=flat-square&logo=react&logoColor=black) ![TrueFoundry](https://img.shields.io/badge/TrueFoundry-2E5BFF?style=flat-square&logoColor=white)

### 🧾 Expense-Approval Agent
An autonomous receipt-processing agent: Gmail → LLM extraction → Google Sheets → Telegram notifications, with a custom polling layer for near-real-time triggering. Built on the Composio v3 SDK with a FastAPI webhook.

![Composio](https://img.shields.io/badge/Composio-6C47FF?style=flat-square&logoColor=white) ![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white) ![Gemini](https://img.shields.io/badge/Gemini-8E75B2?style=flat-square&logo=googlegemini&logoColor=white)

### 🔧 Second Opinion / Parts Oracle — Repair-Quote Analyzer
Analyzes car repair quotes against a reference price table to flag overcharges. The Parts Oracle variant runs as an autonomous agent that monitors retailer prices, computes benchmarks in ClickHouse, and publishes cited reports.

![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=flat-square&logo=fastapi&logoColor=white) ![React](https://img.shields.io/badge/React-61DAFB?style=flat-square&logo=react&logoColor=black) ![ClickHouse](https://img.shields.io/badge/ClickHouse-FFCC01?style=flat-square&logo=clickhouse&logoColor=black) ![Gemini](https://img.shields.io/badge/Gemini-8E75B2?style=flat-square&logo=googlegemini&logoColor=white)

### 📊 Sports Betting Analytics Platform
NBA-first player-prop modeling with closing-line-value validation against Pinnacle, separate minutes-projection and per-stat production models, historical ingestion via `nba_api`, and ESPN endpoints as a live fallback.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![nba_api](https://img.shields.io/badge/nba__api-C8102E?style=flat-square&logoColor=white) ![Modeling](https://img.shields.io/badge/Modeling-11557C?style=flat-square&logo=scipy&logoColor=white)
